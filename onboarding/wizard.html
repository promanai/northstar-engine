Аудит подготовки сайта

Локальный отчёт об исходниках, не проверка опубликованного сайта. Просмотр не меняет ответы и статусы паспорта.

Создайте отчёт в каталоге нужного сайта и выберите полученный файл:

npm run launch -- audit --mode lite --json --output .northstar-launch/source-audit.json

Для Standard укажите --mode standard. Выберите новое имя файла, если отчёт уже существует. Сервер мастера не читает файлы автоматически.
