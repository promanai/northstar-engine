## Проверка и блокировка выпуска

```sh
npm ci
npm run audit:security
npm audit --omit=dev
npm test
npm run lint
npx tsc --noEmit --incremental false
npm run build
npm run test:integration
npm run test:lite
```

`audit:security` проверяет всё дерево, включая devDependencies, и возвращает
ненулевой код при High/Critical или ошибке аудита. Moderate не блокируют этот
порог, но остаются видны. Проверка добавлена в CI, а также в build/deploy jobs
workflow обновления движка. Проверки запускаются до выдачи секретов команде
деплоя. Workflow обновления теперь проверяет и Standard, и Lite.

Не применять `npm audit fix --force` автоматически: предлагаемый аудитом
откат drizzle-kit на старую несовместимую версию не является безопасным
исправлением инструмента миграций.

## Оставшиеся ограничения

После обновления production-аудит не сообщает известных уязвимостей.
Полный аудит сообщает четыре Moderate-узла одной цепочки:
`drizzle-kit → @esbuild-kit/esm-loader → @esbuild-kit/core-utils → esbuild`.
Старый esbuild относится к инструментам разработки/миграций. Не публиковать
dev-серверы или Drizzle Studio в интернет; это временное ограничение, а не
доказательство отсутствия риска. Миграционный инструментарий требует отдельного
совместимого обновления с проверкой генерации SQL.

Количество предупреждений зависит от текущей базы npm advisories. Нулевой
production-аудит не доказывает безопасность приложения и не заменяет проверку
API, загрузок, финансовых лимитов AI, реальных интеграций и облачного запуска.

Изменения проверяются локально. В рамках этого шага нет миграций базы,
публикации Worker, реальных платежей или платных AI-вызовов.

Подтверждено после чистого `npm ci`: production build, TypeScript, линтер,
56 модульных тестов, 110 интеграционных проверок Standard и 10 Lite;
preflight Lite и локальный контракт (10 OpenAPI paths, health, каталог, llms).
Интеграционные проверки использовали отдельные тестовые хранилища.

Сборка выполнена штатным `npm run build`: Windows-обёртка Sites не нашла
`node_modules/npm/bin/npm-cli.js`. Это ограничение обёртки, а не ошибка сборки
движка. Браузерная и облачная приёмка в этот шаг не входят.

Основание для обновления RSC: [уведомление разработчиков React](https://github.com/react/react/security/advisories/GHSA-wx67-qw84-cm4g).
