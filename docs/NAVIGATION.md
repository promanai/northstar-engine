# Меню и вкладки

В Standard появился раздел админки «Навигация» (/admin#navigation): добавление/удаление пунктов, названия, порядок, видимость, выбор назначения и история версий. Lite сохраняет прежнюю навигацию без D1; редактирование через админку в Lite не включено.

В каждом списке до 12 пунктов. Вкладки содержат встроенные разделы chat/quick/modules или опубликованные страницы. Чат всегда остаётся видимым. Верхнее меню ведёт на встроенный раздел, каталог или страницу. Для страницы можно выбрать модальное окно; её обычный ЧПУ-адрес остаётся доступен для SEO и открытия в новой вкладке.

Страницы адресуются по постоянному ID. Публичные ссылки получают текущий slug при серверном рендеринге. Черновики, корзина и невидимые пункты не попадают в публичную конфигурацию. Публичный endpoint содержимого игнорирует административные cookies и никогда не возвращает черновик.

## API и MCP

- GET /api/navigation — только публичные menu/tabs с вычисленными href.
- GET /api/navigation?view=admin — исходные value и revision; нужен owner/admin и site:read.
- PUT /api/navigation — revision, value, confirm: true; нужен owner/admin и site:write.
- GET /api/navigation?view=history — журнал; before/nextBefore листают по 50 записей.
- PUT /api/navigation с revision, targetRevision, confirm: true восстанавливает прошлую конфигурацию новой версией; нужны site:read и site:write.
- GET /api/navigation/page?id=... — только title/slug/blocks опубликованной страницы.
- MCP: navigation_get, navigation_update, navigation_history, navigation_restore.

Пункт: {id, label, kind, target, visible, presentation}. kind: section/page/catalog. target: chat/quick/modules, ID страницы или catalog. presentation: navigate/modal (modal только для страницы в меню). ID встроенной вкладки совпадает с её target; у остальных пунктов уникальный ID из латинских букв, цифр и дефисов.

Сохранение и журнал атомарны. Параллельный проигравший запрос получает 409; MCP — isError. Не подменяйте revision и не повторяйте запись автоматически без согласования конфликта. Восстановление навигации, в отличие от страниц, **сразу действует для посетителей** и требует подтверждения.

## Обновление

Нужна миграция 0011_first_mojo.sql (после предыдущих миграций Standard). Она создаёт site_documents/site_document_revisions без удаления или переноса существующих данных. Миграция в аккаунте владельца автоматически не применялась. До первой записи используется конфигурация по умолчанию; первое сохранение также фиксирует её baseline. Старые установки при недоступности хранилища показывают безопасную стандартную навигацию, а редактор сообщает ошибку.

Настройки через public.navigation в старом /api/settings и site_update_settings отклоняются, чтобы не обходить версии. Остальные настройки пока не переведены на этот механизм. Нет произвольных внешних URL, редактирования программного кода или встроенного админ-агента.

Текущая вкладка браузера обновляется после сохранения; другие открытые вкладки — при возвращении фокуса или перезагрузке. Скрытие страницы не стирает уже загруженный у посетителя текст. История не очищается автоматически и не заменяет резервное копирование.
