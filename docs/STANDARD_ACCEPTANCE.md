# Приёмка Standard перед выпуском

## Автоматически, на изолированных локальных данных

```bash
npm run build
npm run test:acceptance
```

- [x] Полный набор миграций на пустую D1 и проверка журнала.
- [x] Защищённое создание первого администратора, клиенты, вход с паролем.
- [x] Реальные нулевые бизнес-показатели обзора на чистой установке; клиенты, диалоги и обращения в обзоре после восстановления.
- [x] Тот же HTTP smoke, что используется для облачного адреса: 15 проверок с синтетической сессией на собранном Worker; бизнес-таблицы до/после совпадают.
- [x] Согласие на аналитику, посещение, клик и связь с сохранённым диалогом.
- [x] Обращение клиента и ответ администратора.
- [x] Запрет анонимного/чужого доступа к отчётам и приватным данным.
- [x] Экспорт именно выбранной локальной базы и проверка manifest.
- [x] Отказ без указания каталога, при отсутствующем источнике и повторном экспорте поверх файла.
- [x] Отказ восстановления без подтверждения и при повреждении SQL.
- [x] Восстановление в новую базу: строки всех таблиц, структура, внешние ключи, журнал миграций.
- [x] Повторное применение миграций без изменений данных.
- [x] Вход после восстановления, переписка обращений, восстановление и повтор ответа чата, аналитика.
- [x] Фоновое событие очищает истёкшую аналитику без HTTP-посещений; бизнес-таблицы и свежие события не меняются.
- [x] Неизвестное расписание пропускается, повреждённый срок хранения завершает задание ошибкой без удаления.
- [x] Lite игнорирует фоновую задачу без D1/R2.

Проверка выполняется на собранном Worker с demo AI. Внешние HTTP-запросы Worker блокируются. Файл `.test-state-acceptance-*/acceptance-report.json` фиксирует фактический результат конкретного запуска; галочки выше описывают реализованное покрытие, а не заменяют отчёт. Инструкции backup/restore и ограничения: [OPERATIONS.md](OPERATIONS.md).

## До production остаётся

Для уже развёрнутого сайта добавлена [безопасная HTTP-проверка и порядок облачной приёмки](CLOUD_ACCEPTANCE.md). Реализация инструмента и его локальный PASS не закрывают пункты ниже.

- [ ] Браузерная проверка входа, кабинета, админки и аналитики на телефоне и компьютере.
- [ ] Чистое развёртывание Standard в отдельном Cloudflare-окружении владельца.
- [ ] Проверка обновления существующей Standard-установки и восстановления remote D1.
- [ ] Согласованное резервирование/восстановление R2 вместе с D1.
- [ ] Реальные AI, голос, оплата и возврат с отдельным разрешением владельца на внешние операции.
- [ ] Нагрузочная проверка, сценарии отказов и эксплуатационные лимиты.

Не переносите тестовые пароли, bootstrap-токен или дампы этого сценария в рабочую установку. Скрипт не принимает адрес живого сайта, аккаунт Cloudflare или рабочий state directory.

Частичная браузерная приёмка выполнена для нового обзора администратора: синтетический вход, периоды 24 часа/7/30 дней, обновление, переход в обращения, десктоп и ширины 390/320 px без горизонтального переполнения. Это не закрывает проверку всех экранов, тем и реальных мобильных устройств.
