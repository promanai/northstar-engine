# Проверка публичного интерфейса Lite

## Исправлено

- Northstar: вместо кислотного зелёного — графитовые поверхности и спокойный светло-синий акцент.
- Явные theme-aware цвета вкладок при выборе, наведении и фокусе устраняют конфликт цветов базового компонента.
- Поле и отправка выровнены в одной строке; единая рамка фокуса, сенсорная кнопка не меньше 44 px.
- Подсказки перенесены к приветствию; убраны повторяющиеся подписи времени и лишние заголовки.
- На 320 px вкладки не разбиваются посреди слова; длинное имя консультанта не вытесняет кнопку.
- Убрана ссылка на каталог из подвала; каталог доступен в основном меню.
- Ссылки главного меню ведут к главной и её вкладкам также из каталога/контентных страниц.
- Каталог использует общую шапку и более крупный основной текст.
- При ошибке отправки вопрос возвращается в поле без дублирования в истории; показывается причина, есть таймаут.
- UTF-8 контекст Lite укладывается в лимит запроса; ввод ограничен 2000 символами.
- Demo-ответ не показывает сырые Markdown-заголовки.

## Проверки

- Production build, lint, TypeScript — успешно.
- 8 интеграционных проверок Lite — успешно, без внешних AI-запросов.
- Браузер: отправка кнопкой и Enter, Shift+Enter, черновик при переключении вкладок, новый диалог.
- Мобильное меню: открытие, Escape с возвратом фокуса; каталог и переход из каталога во вкладку главной.
- Вкладки: клавиатурный фокус стрелками, выбор Enter; визуальная проверка Northstar, Editorial, Ocean.
- DOM-геометрия на 320, 390 и 1280 px: горизонтального переполнения нет, поле и кнопка выровнены и не перекрываются. На 320 px ширина каждой вкладки вмещает подпись.
- Данные Standard не изменялись; полная регрессия его кабинета и админки в этой UI-итерации не выполнялась.

Ограничения: проверка на физических iOS/Android с экранной клавиатурой и полная accessibility-приёмка не выполнены. Обновлён локальный сервис; облачная публикация по-прежнему требует выбора поддомена OraVera.
