# Файлы и аудиозвонки в Lite

## Вложения

Кнопка «Файл» выбирает одно вложение к следующему сообщению. Файл читается в памяти вкладки, отображается его имя; его можно удалить до отправки. Передача происходит только после «Отправить». При ошибке файл остаётся выбранным для повторной попытки. После успешного ответа бинарное содержимое удаляется из состояния; повторный анализ требует прикрепить файл снова.

- PNG/JPEG/WebP и PDF — до 2 МиБ; TXT/MD (UTF-8) — до 64 КБ.
- Проверяются расширение, MIME, сигнатура, размер и структура запроса. Это не антивирусная проверка и не полный парсер файла.
- Вложения передаются через `POST /api/chat/attachment` непосредственно в запросе Responses, без `/v1/files`, D1 и R2. Тело JSON — до 2 900 000 байт; текстовая история — до 24 000 байт.
- OpenAI обрабатывает изображения/PDF через выбранную модель с поддержкой vision. Текстовые вложения можно отправить OpenAI или xAI. Для изображений/PDF с xAI возвращается явная ошибка 422; эта интеграция пока не реализована.
- Нужны `LITE_AI_ENABLED=true`, соответствующий API-key и `LITE_RATE_LIMITER`. При выключенном AI возвращается 503, файл не объявляется обработанным.
- Движок не хранит файл; обработка и сроки хранения у провайдера определяются его политиками. Не отправляйте чувствительные данные без согласия и подходящих условий провайдера.

## Звонок

Кнопка «Позвонить» открывает окно доступности и предупреждение об отправке аудио OpenAI. Микрофон запрашивается только после «Начать звонок». Во время разговора доступны отключение/включение микрофона, завершение и текст последнего ответа (когда провайдер отдаёт транскрипт). Закрытие окна, уход со страницы и ошибка соединения освобождают микрофон и WebRTC.

Настройки Worker:

```text
OPENAI_API_KEY=<серверный секрет>
LITE_VOICE_ENABLED=true
LITE_VOICE_MODEL=gpt-realtime-mini
LITE_VOICE_VOICE=marin
```

Обязателен отдельный binding `LITE_VOICE_LIMITER`; примеры конфигов используют 3 старта/минуту на IP в точке Cloudflare. Голос включается независимо от текстового провайдера. Standard не получил эту интеграцию: в этой итерации реализован текущий режим Lite.

`GET /api/realtime` возвращает доступность без ключей. `POST /api/realtime` принимает `{confirmed:true,sdp}` и через серверный ключ вызывает OpenAI `/v1/realtime/calls`. В браузер возвращается только SDP. Контекст звонка — публичный каталог, без приватного системного промпта или истории чата. Постоянный ключ не выдаётся клиенту.

Ограничения: браузер завершает звонок через 3 минуты, но это UX-таймер, не серверный финансовый предел. Изменённый клиент может его обойти и менять параметры своей Realtime-сессии. Rate Limiting не ограничивает глобальные расходы или число одновременно активных звонков. Перед публичным включением нужны квоты/контроль расходов провайдера и при необходимости дополнительная антибот-защита. Включение оплачиваемых функций — отдельное действие владельца; по умолчанию они выключены.

Нужны HTTPS (либо localhost), WebRTC и микрофон. Реальный разговор и распознавание файлов должны пройти приёмку с ключом владельца; локальные тесты используют подменённый транспорт без платных запросов.

Источники: [OpenAI WebRTC](https://developers.openai.com/api/docs/guides/realtime-webrtc), [File inputs](https://developers.openai.com/api/docs/guides/file-inputs), [Images and vision](https://developers.openai.com/api/docs/guides/images-vision).
